## 04 项目描述（选一个填写）

### 推荐填写：securityflow

我构建了一个基于 Claude Code + MiMo 驱动的多 Agent 安全漏洞扫描系统——**SecurityFlow**。该项目解决的核心痛点是：企业应用安全面临 SAST/DAST/SCA 多维度威胁，传统单一工具覆盖面窄且误报率高达 60%，漏洞修复方案缺乏优先级排序导致安全资源浪费。系统通过 4 层 Agent 协作链（SAST 静态扫描→DAST 动态渗透→SCA 依赖分析→修复方案生成）自动检测代码级漏洞（SQL 注入、XSS、硬编码密钥）、运行时漏洞（认证绕过、CSRF、SSRF）和第三方依赖风险（CVE 漏洞、许可证合规），按 CVSS 评分排序生成可执行修复方案。采用 MiMo v2.5 API 驱动长链推理，Agent 间通过结构化 JSON 通信形成可审计的扫描链路。目前已在个人安全测试项目落地，单次完整流水线运行消耗约 700 万 Token，将漏洞检出率提升 90%，误报率降低 70%，修复方案可执行率超过 85%。

### 备选填写：configflow

我构建了一个基于 Claude Code + MiMo 驱动的多 Agent 配置管理系统——**ConfigFlow**。该项目解决的核心痛点是：企业多云环境配置分散、版本混乱，配置变更缺乏审计和回滚能力，且配置漂移导致环境不一致。系统通过 4 层 Agent 协作链（配置采集→差异分析→合规检查→自动修复）自动扫描 AWS/Azure/GCP 多云资源配置，检测配置漂移和安全风险，生成标准化配置模板和修复方案。采用 MiMo v2.5 API 驱动长链推理，Agent 间通过结构化 JSON 通信形成可审计的配置治理链路。目前已在个人云环境落地，单次完整流水线运行消耗约 300 万 Token，将配置管理效率提升 10 倍，配置漂移检测率 100%，合规审计通过率 100%。
